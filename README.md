# CMS Application

## Overview

**CMS Application** is a robust and scalable content management system (CMS) built using Laravel. This application is designed to provide an efficient platform for creating, managing, and publishing content with a user-friendly interface and extensive customization options.

---

## Key Features

- **Content Management**: Create, edit, and delete pages, articles, and media files.
- **User Roles and Permissions**: Granular access control for admins, editors, and contributors.
- **Media Library**: Upload, manage, and organize media files efficiently.
- **Customizable Themes**: Integrate and modify themes to match branding.
- **SEO Tools**: Optimize content with metadata and URL management for search engines.
- **Dynamic Dashboard**: Real-time analytics and content management stats.
- **Localization**: Multi-language support to cater to a global audience.
- **Mobile-Responsive Design**: Ensures excellent user experience across devices.

---

## Technical Highlights

- **Laravel Framework**: Leverages Laravel’s powerful MVC architecture for seamless backend operations.
- **Blade Templating**: Clean and efficient UI rendering using Blade templates.
- **Eloquent ORM**: Simplifies database operations with an intuitive query builder.
- **Authentication System**: Secure user login, registration, and password recovery features.
- **RESTful APIs**: Enables integration with third-party tools and services.
- **Testing Suite**: PHPUnit tests for ensuring application reliability.
- **Scalable Design**: Built to handle high traffic and content load efficiently.

## Installation

Follow these steps to set up the CMS application locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/hariskhan802/cms.git
   ```
2. **Navigate to the project directory:**
   ```bash
   cd cms
   ```
3. **Install dependencies:**
   ```bash
   composer install
   npm install
   ```
4. **Set up the environment file:**
   - Duplicate the `.env.example` file and rename it to `.env`.
   - Configure your database and other environment variables in the `.env` file.
5. **Generate application key:**
   ```bash
   php artisan key:generate
   ```
6. **Run migrations:**
   ```bash
   php artisan migrate
   ```
7. **Seed the database (optional):**
   ```bash
   php artisan db:seed
   ```
8. **Compile assets:**
   ```bash
   npm run dev
   ```
9. **Serve the application:**
   ```bash
   php artisan serve
   ```
